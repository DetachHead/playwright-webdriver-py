# Installation

!!! warning

    [The version of `playwright-webdriver-py` on pypi](https://pypi.org/project/playwright-webdriver-py/) is currently unmaintained. [I am in the process of requesting access to publish to it](https://github.com/DetachHead/playwright-webdriver-py/issues/3), so in the mean time, you can install it directly from github instead.

**Requirements:** Python 3.12+

=== "uv (recommended)"

    ```bash
    uv add --dev git+https://github.com/DetachHead/playwright-webdriver-py
    ```

=== "pip"

    ...who still uses pip in current year?

    ```bash
    pip install git+https://github.com/DetachHead/playwright-webdriver-py
    ```
