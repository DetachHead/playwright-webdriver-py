# Credits

I am not the original author of this package. [I found it on pypi](https://pypi.org/project/playwright-webdriver-py) and noticed its github repo was gone. Since I found it useful and needed to make some fixes, I decided to re-publish it and maintain it myself.

The `test_playwright_web_driver.py` test suite started as a Python port of the original C# NUnit test suite from [Selenium.PlaywrightDriver](https://github.com/thomhurst/Selenium.PlaywrightDriver).

Thanks to the original maintainer "happypath" for the initial version of `playwright-webdriver-py`.

!!! info

    Also shoutout to [`chromedriver-py`](https://github.com/breuerfelix/chromedriver-py/) - a pypi package that makes dealing with chromedriver much less of a pain. If `playwright-webdriver-py` doesn't work for your use case, you should check this instead.
